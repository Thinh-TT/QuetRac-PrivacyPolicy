# QuetRac — About & Privacy Policy

Trang web tĩnh công bố thông tin **Về ứng dụng & Chính sách quyền riêng tư** (song ngữ Việt / Anh) cho ứng dụng Android **QuetRac** (100% Offline).

## Triển khai với GitHub Pages

1. Push repo lên nhánh `main` của `https://github.com/Thinh-TT/QuetRac-PrivacyPolicy`.
2. Trên GitHub, mở **Settings → Pages**.
3. Tại mục **Build and deployment**, chọn **Source: Deploy from a branch**, **Branch: `main`**, thư mục **`/ (root)`** rồi nhấn **Save**.
4. Sau khoảng 1–2 phút, trang web sẽ hoạt động tại:
   `https://thinh-tt.github.io/QuetRac-PrivacyPolicy/`
